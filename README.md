## 📥 Установка — за 30 секунд

1. Нажми кнопку **«Скачать»** выше — загрузится один файл `ValorantChecker.exe`.
   Это всё, больше ничего скачивать не нужно: обновления программа ставит сама.
2. Положи файл в любую папку, например на рабочий стол или в `Документы\Valorant Checker`.
   В эту же папку программа будет сохранять готовые картинки.
3. Запусти `ValorantChecker.exe`.

> **Windows пишет «Система Windows защитила ваш компьютер»?**
> Так бывает со всеми программами без платного сертификата. Нажми **«Подробнее» → «Выполнить в любом случае»**.
> Если антивирус удалил файл — добавь его в исключения и скачай заново.

## 🔑 Как оформить подписку

1. Запусти программу — откроется экран **«Активация подписки»** с **кодом компьютера**
   (вида `XXXX-XXXX-XXXX-XXXX`). Нажми **«Копировать»**.
2. Перейди к продавцу на **[FunPay](https://funpay.com/users/5784014/)**, выбери срок и оплати. В сообщении отправь скопированный код.
3. Продавец пришлёт **ключ** (начинается с `VSK-`). Нажми в программе **«Вставить из буфера»** → **«Активировать»**.

Готово — подписка активна, срок виден слева внизу программы.

| Тариф | |
|---|---|
| 1 день · 3 дня · неделя | попробовать |
| месяц · год | для постоянного использования |
| навсегда | один раз и без продлений |

> Ключ привязан к твоему компьютеру и на другом ПК не заработает.
> Переставил Windows или сменил компьютер — напиши продавцу, ключ перевыпустят.

## 🔄 Продление

1. В программе слева внизу нажми **«Продлить»** — появится твой текущий ключ, нажми **«Копировать»**.
2. Отправь его продавцу на **[FunPay](https://funpay.com/users/5784014/)** и оплати новый срок.
3. Вставь полученный ключ и нажми **«Продлить»**. **Оставшиеся дни не сгорают** — новый срок прибавляется к ним.

## 🎮 Как пользоваться

1. Открой **Riot Client** и войди в свой аккаунт. Саму игру запускать не нужно.
2. Запусти Valorant Checker — данные аккаунта загрузятся сами.
3. Выбери раздел слева, настрой картинку справа (заголовок, тема, водяной знак) и нажми **«Сохранить»**.
   **«Сохранить всё»** — все разделы разом. Готовые файлы — в папке рядом с программой (кнопка «Открыть папку»).

## 🔒 Безопасно ли это

- Программа **не спрашивает логин и пароль**. Она берёт данные только у уже запущенного Riot Client на твоём ПК —
  так же, как это делает сам лаунчер.
- Ничего не меняет в аккаунте и в игре — только читает и рисует картинки.
- Обновления подписаны продавцом: программа проверяет подпись и не установит чужой файл.

## ❓ Частые вопросы

**«Riot Client закрыт» / «Не выполнен вход в Riot Client»** — открой лаунчер, войди в аккаунт и нажми «Обновить».

**Ключ не подходит** — проверь, что скопировал его целиком. Ключ, выданный для другого компьютера, не заработает.

**Как обновить программу?** — никак, она обновляется сама при запуске. Если захочешь вручную — просто скачай
файл по кнопке выше и замени старый. Подписка при этом сохранится.

**Скачал не тот файл?** — в разделе Releases GitHub сам добавляет архивы «Source code», они не нужны.
Нужен только `ValorantChecker.exe`.
